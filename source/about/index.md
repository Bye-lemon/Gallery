# 关于我们的AI艺术画廊

这是一个展示AI生成艺术作品的画廊网站。我们收集了使用各种AI艺术生成平台创建的精美图像，包括但不限于Midjourney、DALL-E和Stable Diffusion等。

## 收集方式

所有展示的图像都基于精心设计的提示词(Prompt)创建，并记录了生成它们的平台。我们希望通过分享这些信息，帮助艺术爱好者了解不同AI平台的特点和能力。

## 技术实现

本网站基于Hexo框架构建，使用了以下技术：

- Hexo静态网站生成器
- 瀑布流布局展示图片
- 响应式设计，适配各种设备
- GitHub Actions自动部署
